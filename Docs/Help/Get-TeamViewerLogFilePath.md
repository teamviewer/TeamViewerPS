# Get-TeamViewerLogFilePath

## SYNOPSIS

Retrieves TeamViewer log files.

## SYNTAX

```powershell
Get-TeamViewerLogFilePath
```

## DESCRIPTION

The command checks the required directories and returns the paths for log files.

## EXAMPLES

### Example 1

```powershell
PS /> Get-TeamViewerLogFilePath 
```

Returns the paths for log files.
